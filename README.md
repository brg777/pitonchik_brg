# task1-int-optimization

Задание №1. Диапазон оптимизацаии выделения памяти под объекты int

Найти максимальный диапазон целых чисел [-M,N], для которого вышеобозначенное утверждение верно (id(a) == id(b)).

Решил сделать в два цикла: сначала к переменным 'a' и 'b' (a = 0, b = 0) прибавлял по 1 каждый цикл. Если (id(a) == id(b)) = False, то условие для некоторых значений перестало выполняться. Переменная 'N' получает значение a-1, так как для значения 'a' условие уже не выполняется. Переменные 'a' и 'b' получают новое значение 0. Аналогично второй цикл работает уже убавляя значение по 1. После while переменной 'M' присваиваем значение 'a + 1', так как опять же для 'a' условие уже не выполняется. По итогу программа выводит два числа - диапазон целых чисел - -5 256
