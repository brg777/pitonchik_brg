# task1-int-optimization

Задание №1. Диапазон оптимизацаии выделения памяти под объекты int

Найти максимальный диапазон целых чисел [-M,N], для которого вышеобозначенное утверждение верно (id(a) == id(b)).

Задача решена с помощью функции, которая в зависимости от логической переменной прибавляет или убавляет из двух нулевых переменных единицу; функция возвращает значение, при котором две переменные еще имею одиннаковый id. По итогу программа выводит два числа - диапазон целых чисел - -5 256  

Запуск проекта: 

> cd task1/src

> poetry run python -m task1
